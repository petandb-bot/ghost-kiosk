# iPhone PWA setup

1. Upload this whole folder to an HTTPS host such as GitHub Pages.
2. Open the published URL in iPhone Safari.
3. Tap Share.
4. Choose **Add to Home Screen**.
5. Launch GHOST KIOSK from the new home-screen icon.

The service worker uses cache name `ghost-kiosk-v1.7.1`; deploying this version should replace the v1.7 local cache after reload.
